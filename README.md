# senai-atividade-versionamento
solução de conflitos

## Objetivo
Demonstrar o uso de versionamento com branches, commits, merge e resolução de conflitos.

## Arquivos
- `index.html`: página principal da atividade.
- `README.md`: documentação do processo e da resolução.

## Histórico e evidências
- `dcf051c` — "Add initial index.txt for versionamento activity"
- `feature/index-html` — atualização do HTML principal e documentação da atividade.
- `feature/conflict-test` — branch criada para simular um conflito de merge em `index.html`.

## Simulação de conflito
A branch `feature/conflict-test` foi criada para alterar o mesmo elemento HTML do arquivo `index.html`, reproduzindo um cenário clássico de conflito ao fazer merge.

A solução final foi consolidada na branch `feature/index-html`, onde a versão estável do projeto foi mantida com o conteúdo correto da atividade de versionamento.

## Resultado final
A página principal está em HTML válido, com estrutura correta e conteúdo relacionado à atividade de versionamento.
